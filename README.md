# veninDroidSynthKick
Un vrai VST ne tourne pas sur Android, c'est un format desktop. J'ai donc fait un synthé qui tourne directement dans Chrome sur ton téléphone : Venin. Ouvre la page et touche une note pour lancer le son.

Sons : deux tables d'ondes avec morphing (sinus, triangle, scie, carré, impulsion, screech), unisson jusqu'à 7 voix, sub, et une chute de pitch pour les kicks gabber.
Wobble : filtre 24 dB avec LFO relancé à chaque note, synchro au tempo (1/8, 1/16, triolets) ou vitesse libre, plus enveloppe de filtre.
Hardcore : distorsion douce, dure ou à repli, et un limiteur en sortie pour éviter la saturation.
Presets : Wobble, Reese, Screech, Kick gabber, Supersaw.
Jeu : clavier tactile multi-touch, bouton Hold pour tourner les boutons pendant qu'une note sonne, et MIDI USB si tu branches un clavier.

Ce n'est pas un vrai clone de Serum : pas d'import de wavetables ni de matrice de modulation. Tu peux le mettre sur l'écran d'accueil depuis le menu de Chrome. Pour le wobble à 150 BPM, règle le tempo, choisis une division dans le LFO et monte la profondeur.
